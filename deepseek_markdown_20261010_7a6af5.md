# 🎓 Telegram-бот для анкет выпускников

Бот собирает анкеты выпускников: ФИО, контакты, школу, планы.
Ответы сохраняются в `surveys.csv`, админ получает уведомления.

## Команды
- `/start` — начать анкету
- `/cancel` — отменить
- `/stats` — количество анкет (админ)

## Переменные окружения
| Переменная | Описание |
|-----------|----------|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | Ваш Telegram ID |
