# 🎓 Telegram-бот для анкет выпускников

Бот собирает анкеты выпускников школ. Ответы сохраняются в `surveys.csv`,
администратор получает уведомления о новых анкетах.

## Команды
- `/start` — начать заполнение
- `/cancel` — отменить
- `/stats` — количество анкет (только админ)

## Переменные окружения
| Переменная | Описание |
|-----------|----------|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | Ваш Telegram ID от @userinfobot |

## Запуск
python bot.py
